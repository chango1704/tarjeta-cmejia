# Tarjeta digital · Claudia Patricia Mejía Pérez

Tarjeta de presentación digital de GEOTEC Ingeniería LTDA.

**Sitio publicado:** https://geotec-ing.github.io/tarjeta-cmejia/

Incluye contacto, WhatsApp, guardar contacto (.vcf), LinkedIn, Corporate Book 2026 y código QR para compartir.

## Archivos

| Archivo | Para qué sirve |
|---|---|
| `index.html` | La tarjeta completa. Fuentes, logo y QR van dentro del archivo: no depende de internet para verse. |
| `foto.jpg` | Fotografía del círculo. Para cambiarla, suba otra con este mismo nombre, cuadrada. |
| `claudia-mejia.vcf` | Contacto que se descarga al tocar "Guardar contacto". |
| `GEOTEC_Corporate_Book_2026.pdf` | Corporate Book, versión sin transparencias para que se vea bien en celular. |
| `og.jpg` | Vista previa al compartir el enlace por WhatsApp o LinkedIn. |
| `icon-192.png`, `apple-touch-icon.png` | Ícono al guardar la tarjeta en la pantalla de inicio. |
| `.nojekyll` | Le dice a GitHub Pages que publique los archivos tal cual. No borrar. |

## Para actualizar

Subir el archivo nuevo con el mismo nombre. GitHub Pages se actualiza solo en uno o dos minutos.
